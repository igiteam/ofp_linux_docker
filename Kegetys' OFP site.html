DXDLL v1.0

Adds reflective water, postprocessing effects, trilinear filtering
and other new features to OFP. Use this thread in the official
OFP forums for troubleshooting.

A special version for VBS is also available.

Spectating Script v1.2

A script for multiplayer mission designers which allows dead
players to spectate others. Includes multiple camera angles with
adjustable distance, easy to use interface and seagull mode.

The newest version is included in FDFmod

Hisky v1.0c

Adds new, higher resolution sky textures and improves the
rainy weather texture and fog colors. Installer requires
a Windows NT based operating system (ie. Windows 2000 or XP)

Linuxarch v1.0

Automatically packages files from a windows OFP installation
into a TAR(.gz) archive, to be extracted on a linux system
for dedicated server installation. Only a very minimal amount
of files required by the dedicated server are packed, to make
the package as small as possible.

OFP Launcher v2.18

A Launcher for OFP, supporting mods, joining to multiplayer servers,
querying servers and an automatic server watcher with a sound notification
of new games.

TGA2ASE v1.0

Converts a TGA based "heightmap" image into ASE format, which can be
imported into Visitor for easy terrain heightmap generation.
